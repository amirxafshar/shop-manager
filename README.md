🛒 Shop Management App (Windows Forms)

A desktop shopping application built using C# and Windows Forms.
This project simulates a simple e-commerce experience with a clean and user-friendly interface.

✨ Features
🛍️ Browse available products
➕ Add items to shopping cart
➖ Remove items from cart
🧾 View selected items and total price
💻 Simple and responsive desktop UI
🧰 Technologies Used
C# (.NET Framework / .NET)
Windows Forms (WinForms)
Visual Studio
